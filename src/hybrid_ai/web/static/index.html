3 · How to read this

The four stages

  1. CLIPS rules — picks the insert, writes the CAPP operation plan and its setup & fixturing plan, and returns a safe envelope from ISO + operation + machine.
  2. Wear model — predicts flank wear VB and roughness Ra at a given setting.
  3. Fuzzy logic — turns those numbers into safe / caution / critical, with a reason.
  4. NSGA-II — searches the envelope for settings that balance output, tool life and finish.

What the numbers mean

TermMeaning
VBFlank wear in mm. Bigger = more worn = change the insert.
RaSurface roughness in µm. Smaller = smoother finish.
MRRMaterial removal rate, cm³/min. Bigger = faster cutting.
LifeEstimated minutes before the insert wears out.
EnvelopeSafe range of speed / feed / depth for the chosen insert.
Wear model: blended MLP (synthetic + NASA) · CAPP + setup & fixturing plan · fuzzy safety gate · NSGA-II optimiser · 50-insert ISO 13399 catalog · runs fully offline
