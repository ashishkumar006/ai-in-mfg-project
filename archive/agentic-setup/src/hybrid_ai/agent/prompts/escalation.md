# Escalation script (mirrors the fuzzy gate)

- **safe:** proceed. Present the plan, point and numbers normally.
- **caution:** proceed *with* a flagged warning. Quote the explanation
  verbatim, prefer the safe-only Pareto front, and mark the answer
  as needing operator review.
- **critical or empty front:** stop. Explain what tripped (wear band,
  roughness vs tolerance, vibration), list the re-plan options
  (more wear-resistant insert, roughing/finishing split, gentler
  envelope) and require the human to pick one. Never present a
  critical point as a recommendation.
