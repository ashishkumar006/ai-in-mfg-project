# data/

This folder is intentionally committed empty.

- `raw/` — place the NASA Milling dataset and Sandvik ISO 13399
  catalog exports here when available.
- `processed/` — generated features and model artefacts.
- `synthetic/` — synthetic fixtures used by the prototype and tests
  when real data is unavailable.

The SQLite database file (`*.db`, `*.sqlite`) is gitignored.
